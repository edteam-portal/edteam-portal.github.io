[ DIAGNOSTIC 1 ] : MOTEUR EDMC

L'application Elite Dangerous Market Connector (EDMC) est obligatoire. C'est elle qui lit les données de votre jeu en temps réel.

1. Téléchargez EDMC via le lien sécurisé ci-dessous et installez-le.
2. Lancez l'application sur votre PC.
3. Connectez-y votre compte Frontier / Elite Dangerous.

🌐 TÉLÉCHARGER EDMC (GITHUB OFFICIEL)

[ DIAGNOSTIC 2 ] : LE PLUGIN EDTEAM

Pour que EDMC puisse nous parler, il lui faut notre module de communication privé.

1. Téléchargez le fichier ZIP ci-dessous.
2. Sur EDMC, allez dans Fichier > Paramètres > Plugins.
3. Cliquez sur "Ouvrir" et décompressez le dossier SYS_EDTEAM à l'intérieur.
4. Fermez et relancez complètement EDMC.

📦 TÉLÉCHARGER LE PLUGIN (SYS_EDTEAM.zip)

[ DIAGNOSTIC 3 ] : LA CLÉ DE LIAISON

Si le module est installé, il faut l'autoriser à transmettre en votre nom.

1. Cliquez sur la clé ci-dessous pour la copier.
2. Dans EDMC, allez dans Fichier > Paramètres.
3. Allez dans l'onglet SYS.EDTEAM, collez la clé et validez (OK).

[ CHARGEMENT DE LA CLÉ... ]

[ DIAGNOSTIC 4 ] : INITIALISATION DU TRANSPONDEUR

Le réseau ne peut pas deviner votre identité. L'application a besoin que vous soyez connecté à votre vaisseau dans Elite Dangerous pour lire et enregistrer votre Nom de Commandant.

1. Lancez Elite Dangerous sur votre machine.
2. Entrez dans votre vaisseau (Jeu Ouvert, Groupe Privé ou Solo).
3. Patientez quelques secondes. Dès que le signal sera capté, ce verrouillage de sécurité sautera automatiquement !
