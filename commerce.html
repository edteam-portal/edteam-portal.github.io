Pour accéder au terminal, votre système doit être correctement synchronisé. Identifiez votre problème :

[ DIAGNOSTIC 1 ] : MOTEUR EDMC

L'application Elite Dangerous Market Connector (EDMC) est obligatoire.

1. Téléchargez EDMC via le lien sécurisé ci-dessous et installez-le.
2. Lancez l'application sur votre PC.
3. Connectez-y votre compte Frontier / Elite Dangerous.

🌐 TÉLÉCHARGER EDMC

[ DIAGNOSTIC 2 ] : LE PLUGIN EDTEAM

Pour que EDMC puisse nous parler, il lui faut notre module de communication privé.

1. Téléchargez le fichier ZIP ci-dessous.
2. Sur EDMC, allez dans Fichier > Paramètres > Plugins.
3. Cliquez sur "Ouvrir".
4. Décompressez le dossier SYS_EDTEAM à l'intérieur.
5. Fermez et relancez complètement EDMC.

📦 TÉLÉCHARGER LE PLUGIN

[ DIAGNOSTIC 3 ] : LA CLÉ DE LIAISON

Si le module est installé, il faut l'autoriser à transmettre en votre nom.

1. Copiez la clé ci-dessous.
2. Dans EDMC, allez dans Fichier > Paramètres.
3. Allez dans l'onglet SYS.EDTEAM.
4. Collez la clé et validez (OK).

[ CHARGEMENT DE LA CLÉ... ]

[ DIAGNOSTIC 4 ] : INITIALISATION

Le réseau a besoin que vous soyez connecté à votre vaisseau dans Elite Dangerous pour lire et enregistrer votre Nom de Commandant.

1. Lancez ou relancez Elite Dangerous.
2. Entrez dans votre vaisseau (Jeu Ouvert, Groupe Privé ou Solo).
3. Rafraîchissez cette page (F5) dès que vous êtes dans le cockpit.

[ BRIEFING TACTIQUE ] : RECHERCHE DE VENTES

Le système va analyser les soutes de votre Fleet Carrier et de votre Vaisseau.

  • Extraction des 4 marchandises les plus importantes en volume.
  • Croisement avec le réseau pour trouver les meilleurs acheteurs.
  • Tri par rentabilité et proximité depuis votre position actuelle.
X

[ BRIEFING TACTIQUE ] : ANALYSE PRÉDICTIVE

> PROTOCOLE DE TÉLÉMÉTRIE : Pour confirmer une analyse prédictive, un vaisseau de l'escadron doit impérativement se rendre sur les coordonnées du système ciblé. Une fois amarré pour établir l'accès réseau local, le terminal croisera l'intégralité des données du marché avec nos algorithmes pour révéler les filons cachés.

Le système va interroger le Background Simulation (BGS) et les archives furtives de l'escadron.

  • Analyse des économies (Extraction, Agricole, Haute Technologie...) et détection des états critiques du BGS (Boom, Épidémie, Famine...).
  • Identification des opportunités d'achat non déclarées sur le réseau public.
  • Analyse des tendances locales.
