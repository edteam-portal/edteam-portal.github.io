[ DIAGNOSTIC 1 ] : MOTEUR EDMC

L'application Elite Dangerous Market Connector (EDMC) est obligatoire.

1. Téléchargez EDMC via le lien sécurisé ci-dessous et installez-le.
2. Lancez l'application sur votre PC.
3. Connectez-y votre compte Frontier / Elite Dangerous.

🌐 TÉLÉCHARGER EDMC

[ DIAGNOSTIC 2 ] : LE PLUGIN EDTEAM

Pour que EDMC puisse nous parler, il lui faut notre module de communication privé.

1. Téléchargez le fichier ZIP ci-dessous.
2. Sur EDMC, allez dans Fichier > Paramètres > Plugins.
3. Cliquez sur "Ouvrir".
4. Décompressez le dossier SYS_EDTEAM à l'intérieur.
5. Fermez et relancez complètement EDMC.

📦 TÉLÉCHARGER LE PLUGIN

[ DIAGNOSTIC 3 ] : LA CLÉ DE LIAISON

Si le module est installé, il faut l'autoriser à transmettre en votre nom.

1. Copiez la clé ci-dessous.
2. Dans EDMC, allez dans Fichier > Paramètres.
3. Allez dans l'onglet SYS.EDTEAM.
4. Collez la clé et validez (OK).
